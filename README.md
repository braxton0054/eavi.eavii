# EAVI — East Africa Vision Institute

A full-stack college management system built with **Next.js 16** and **Supabase**.

## Quick Start

```bash
npm install
npm run dev
```

## Documentation

See [`CLAUDE.md`](./CLAUDE.md) for full project context, architecture, and setup details.

## Live URLs

- **Dashboard:** https://office-dashboard.vercel.app
- **Website:** https://eavi.shop
- **File Storage:** https://files.eavi.shop

## Key Features

- Multi-role dashboards (Admin, Student, Lecturer)
- Student enrollment with document upload
- Course & programme management (CDACC & JP accredited)
- Financial system (fees, payments, installments, bursary)
- AI campus chatbot (Groq + NVIDIA)
- Email notifications (Gmail SMTP + Resend)
- Bridge programme management
- Financial reporting with Chart.js
